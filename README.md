### Three questions, three builds

**01 / Is this traffic abusive, or just busy?**

[Sentinel](https://github.com/rupeshhh007/sentinel-api-abuse-detection) — API abuse detection with inspectable decisions, Redis-backed rate windows, and an attack lab for replaying traffic. Built with Java, Spring Boot, Redis/Lua, and React.

**02 / When should a service stop trying?**

[Aegis](https://github.com/rupeshhh007/aegis-circuit-breaker) — A circuit breaker built around sliding windows, explicit state transitions, and recovery probes. Spring WebClient handles the outbound calls; the breaker decides whether they should happen.

**03 / Who gets filled first?**

[Order matching engine](https://github.com/rupeshhh007/high-performance-matching-engine) — Price-time priority, in-memory order books, a separate settlement path, and WebSocket market updates. Java, Spring Boot, and PostgreSQL.

### Also on the workbench

**[Wordle Arena ↗](https://wordle-arena-two.vercel.app/)** — Daily puzzles, practice, and ranked 1v1 matches with Elo ratings. Spring Boot + Next.js. Five letters turned into a whole backend.

**[Internet Museum, 1995–2005](https://github.com/rupeshhh007/internet-museum-1995-2005)** — An early-web playground with desktop windows, an email client, a terminal, and a live HTML editor. A place for the blinking cursor to feel at home.
