## Featured Project

### QuerySense AI

**SQL query analysis and optimization using machine learning + LLMs.**

QuerySense AI combines SQL parsing, feature engineering, ML-based latency prediction, and LLM-assisted query rewriting into a single workflow.

**Pipeline**

```text
SQL Query
   ↓
SQL Parser
   ↓
AST / Query Features
   ↓
Latency Prediction
   ↓
Bottleneck Detection
   ↓
LLM-assisted Rewrite
   ↓
Optimized Query
```

**Built with**

`Python` `FastAPI` `LightGBM` `SQL Parsing` `Groq` `Llama 3` `Streamlit`
